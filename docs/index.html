Convert images without sending them anywhere.

Flux is a Windows desktop converter for JPG, PNG, WebP, ICO, AVIF and GIF - every format converting to every other. It runs entirely on your machine: the only network request it ever makes is the optional update check.

Download the installer v0.2.0 Windows only

Overview

What it does

Drop in a folder of images, pick a target per row, and convert the lot in one pass. Progress is per-file, so a batch that partly fails still tells you which files made it.

  • Batch conversionQueue as many files as you like; rows are grouped by target format and each finishes with its own status.
  • Six formats, both directionsJPG, PNG, WebP, ICO, AVIF and GIF. The backend declares what it can write, so the app never offers a target it cannot produce.
  • Conversion options where they matterA quality slider for lossy targets and a dithering toggle for GIF, shown only when a pending row targets a format that uses them.
  • Icons and animation handled properlyICO output carries 16, 32, 48 and 256px frames at once, square-padded with real transparency. Animated sources keep every frame, its duration and its disposal when written to GIF.
  • Colour profiles preservedAVIF output carries the source ICC and XMP data rather than silently reinterpreting it as sRGB.
  • Offline-firstNo CDN, no telemetry, no uploads. Vue, Tailwind and Inter are all shipped inside the installer.

Thirty conversion paths

Every format converts to every other - 30 pairs, all verified. Converting an image to the format it is already in is not offered, because re-encoding it changes nothing.

Rows are the source format, columns the target. A dash means that pair is not offered because the formats match.

Transparent formats stay transparent everywhere they can: PNG, WebP, ICO, AVIF and GIF all carry alpha. JPG flattens it onto white, because JPEG has no alpha channel to flatten into.
